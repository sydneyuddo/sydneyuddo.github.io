# Sydney Uddo — Portfolio Website

Personal portfolio site for Sydney Uddo, a Political Science & Psychology student at Tulane University preparing for law school.

## How it's built

- `index.html` — all of the page content (sections: About, Experience, Leadership, Education & Skills, Contact)
- `styles.css` — the design: colors, fonts, layout, and the phone/tablet layout rules at the bottom
- `favicon.svg` — the small "SU" icon shown in the browser tab

It's a plain HTML/CSS site with no build step, so GitHub Pages can serve the files as-is.

## Editing

- To change text, edit `index.html` and push to `main`. The live site updates in about a minute.
- To add a headshot, save it as `images/headshot.jpg` and follow the comment in the hero section of `index.html`.
